# LumaCue v0.2.0: desktop app for Windows, Linux and macOS 🖥️

LumaCue Show Studio now runs as a native desktop app, with a new look and a security overhaul.

## Downloads
| System | File |
|---|---|
| Windows 10/11 (64-bit) | `LumaCue-Setup-0.2.0-win-x64.exe` |
| Ubuntu / Debian | `LumaCue-0.2.0-linux-amd64.deb` |
| Any Linux | `LumaCue-0.2.0-linux-x86_64.AppImage` |
| macOS (Apple Silicon) | `LumaCue-0.2.0-mac-arm64.dmg` |
| macOS (Intel) | `LumaCue-0.2.0-mac-x64.dmg` |

Check your download against `SHA256SUMS.txt`.

**First launch:** the installers are not code-signed yet.
- **Windows:** SmartScreen → *More info* → *Run anyway*.
- **macOS:** right-click the app → *Open*.
- **Linux:** run `sudo usermod -aG dialout $USER`, then log out and back in, to use the USB base station.

You can also run the web version in Docker: `docker build -f lumacue/Dockerfile -t lumacue .`, then `docker run -p 127.0.0.1:3000:3000 lumacue`.

## New
- 🖥️ **Desktop app** (Electron): own window, animated splash screen, and a native picker for the base station's USB port. The costume firmware is bundled, so firmware downloads work offline.
- ✨ **New logo and login animation:** the LumaCue "L" made of LED dots lights up like a costume chase.
- 🔐 **Your own access code:** on first start you choose a code. Only a salted PBKDF2 hash is stored, and the form locks after repeated wrong codes. **The old built-in code has been removed.**
- 🐳 **Docker image** for the web version.
- ⚙️ **Automatic builds:** every version tag builds and tests all installers on GitHub.

## Security
- Desktop app hardened: sandboxed pages with no Node.js access, navigation and popups locked to the app, only the USB-serial permission granted, and the local server bound to `127.0.0.1` with DNS-rebinding protection.
- Raspberry Pi hardware server: access token (`WS_TOKEN`), origin allow-list and message size limit. Before this, anyone on the same Wi-Fi could control the lights.
- Dependencies updated: Next.js 16.4.6 (fixes a critical denial-of-service advisory), Electron 42.11.18 (sandboxed-popup advisories), vitest 5, and patched ws, PostCSS, sharp, nanoid and brace-expansion. **0 known vulnerabilities in the shipped app.**
- 15 new automated security tests. See [SECURITY.md](https://github.com/aswinsamuel-codes/LumaCue/blob/v0.2.0/lumacue/SECURITY.md).
