# LumaCue v0.1.0: first public release (alpha) 🎉

LumaCue is now open source: design light shows for LED dance costumes on a music timeline, preview them on a digital twin, generate the costume firmware, and run the show live in sync with the music.

## Highlights
- 🎵 **Show Studio:** waveform, beat grid and energy sections, plus **✨ Auto cues** that drafts a show from the song
- 🕺 **Digital twin:** 3D preview of every dancer, exactly as the firmware will light it
- 🔧 **Firmware generator:** Arduino sketches per dancer, with preflight (cue budget, power, battery runtime) and a cue sheet
- 📡 **Show Mode:** ARM, START, instant BLACKOUT, rehearse from any section, music sync every 2 s
- 🧪 **SIMULATE:** run a whole show with no hardware, using a virtual base station and costumes
- ☁️ **Cloud firmware builds:** drop a show into `firmware/shows/` and GitHub Actions compiles it
- ✅ **170+ tests** that keep the TypeScript twin and the C++ firmware in step

## Hardware
| | Bench prototype | Show costume |
|---|---|---|
| Board | Arduino Nano + NRF24L01+ | ESP32 (ESP-NOW) |
| LEDs | 5 mm bi-colour or WS2812B | WS2812B |
| Status | Compiles; not yet run on hardware | Written; not yet compiled on hardware |

## ⚠️ Alpha: please read
- Not yet tested on real costumes. The first bench test and a live show with about 10 dancers are planned for December 2026.
- The login screen in this release uses a fixed access code checked in the browser. The next release (desktop app) replaces it with a hashed code you choose.
- The radio link is not authenticated yet.

## Get started
```bash
git clone https://github.com/aswinsamuel-codes/LumaCue.git
cd LumaCue/lumacue && npm install && npm run dev
```
